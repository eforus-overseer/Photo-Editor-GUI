# Photo-Editor-GUI · The 2018 original

This is my original Python and Tkinter photo editor, **written 100% by hand in 2018, with no AI assistance**, before the modern AI coding era. The application code is preserved here as a record of that work.

## The modern successor

I have since reimagined the project as **[Efi's Photo Studio](https://github.com/eforus-overseer/photo-studio)**: a separate, AI-assisted project built with Codex under my direction. It retains all 14 original operations and adds a new desktop interface, ten additional filters and segmentation tools, safe batch export, and an interactive website.

**[Try the interactive studio](https://eforus-overseer.github.io/photo-studio/)** · **[Explore the new repository](https://github.com/eforus-overseer/photo-studio)**

The new project includes a generated cheerful Labrador puppy and a credited collection of animal and nature photographs for trying the effects.

## Original interface

![The original hand-written Tkinter photo editor](Pic_editor.jpg)

The original tools include rotation, mirroring, resizing, edge recognition with an adjustable threshold, primary colors, halftone, blur, minimum filtering, sharpening, contour, detail, edge enhancement, emboss, and kernel smoothing. It also supports folder browsing, previews, and batch saving.

## Run the historical app

Use Python with Tk support and Pillow installed, then run:

```bash
python GUI.py
```

For a current installation guide and the maintained implementation, use the [new studio README](https://github.com/eforus-overseer/photo-studio#quick-start).
